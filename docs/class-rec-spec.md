# 学級レク（教員向け）要件定義・仕様書

作成日: 2026-08-07
状態: **実装済み**（2026-08-07）。`/teachers/` 配下で公開している。
本書のうち 3.3 で挙げた「サイトの定義の書き換え」は実施済み（requirements.md 1章）。

---

## 0. この文書について

「隙間時間にできる学級レク」を扱う**完全に教員向け**のページ群を、既存サイトに追加できるかを
検討し、追加する場合の仕様と掲載内容までを定めたもの。

きっかけは学級レクを扱う既存サイトだが、**そのサイトの中身は確認できていない**
（当方の実行環境から到達できなかった）。したがって本書は模倣ではなく、
コンセプトだけを受け取って、このサイトの制約と強みに合わせて設計し直したものである。

## 1. 背景と位置づけ

### 1.1 なぜ今これを検討するか

[concept-review.md](./concept-review.md) の4案のうち **案4「教員向けに戻る」** は、
次の理由で他案と性格が違うと結論していた。

> **流入経路の問題に構造的な答えがある唯一の案。** 教員コミュニティへの導線を本人が持っている。
> SEOで18年物のドメインと戦わなくてよい。

一方で「収益化はほぼ不可能」という弱点も同時に挙げていた。ただし**収益化は当面保留**という
現在の方針の下では、この弱点は実質的なコストになっていない。

また、ゆみねこの教科書（月間100万PV）の分析から、**教員向けの導線を明示することは
低コストで効果が大きい**という示唆も得ている。

### 1.2 「先生の道具箱」の再来ではない

このサイトは2026年7月に教員向け「先生の道具箱」から児童向けへ転換した経緯がある。
今回は**そこへ戻すのではない**。児童向けドリルは主軸のまま変えず、
その隣に独立した教員向けエリアを増設する。

## 2. 要件定義

### 2.1 目的

**授業の残り5分、給食の待ち時間、雨の日の休み時間に、その場ですぐ使えるレクを1つ選べるようにする。**

学級レクの情報自体はネット上に大量にある。しかし多くは「盛り上がる30選」のような**網羅型**で、
準備物が要るもの・体育館が要るもの・15分かかるものが混在している。
**隙間時間にその場で開いた教員にとっては、その大半が使えない。**

そこで本ページは**網羅を捨て、隙間時間で成立するものだけに絞る**ことを設計の中心に置く。

### 2.2 ターゲット

| 区分 | 対象 | 状況 |
|------|------|------|
| 主 | 小学校の学級担任 | 教室で、スマホか校務PCを片手に、1〜2分で1つ選びたい |
| 副 | 教育実習生・初任者 | 引き出しが少なく、失敗しないものを探している |
| 副 | 学童・放課後子ども教室の指導員 | 準備物なしで回せるものを探している |

**児童は読者に含めない。** 文体も導線も教員向けに割り切る。

### 2.3 掲載する条件（これが差別化の核）

次を**すべて**満たすものだけを載せる。1つでも欠けたら載せない。

1. **5分以内に終わる**（説明込み）
2. **準備物が「なし」または「黒板とチョーク」まで**
3. **教室で成立する**（体育館・校庭を必要としない）
4. **ルール説明が30秒で済む**
5. **人数が多少ぶれても成立する**（欠席がいても回る）

### 2.4 スコープ

**やること**

- 隙間時間向けレクの一覧と個別ページ
- 現場の条件で絞り込める仕組み
- 授業での利用（印刷・投影）に関する案内

**やらないこと**

- 会員登録、投稿機能、コメント欄
- レクの数を競うこと（**網羅しない**のが方針）
- 体育館・校庭・行事向けの大がかりなレク
- 動画
- 児童向けの見せ方（ひらがな化など）

### 2.5 非機能要件

既存サイトの方針をそのまま引き継ぐ。

- **サーバーを持たない。** 静的エクスポートのまま
- **登録不要・ログインなし**
- **個人情報を扱わない**
- スマホでの閲覧を第一に設計する（教室で片手で見る）
- 印刷して職員室に置ける体裁にする

## 3. 既存サイトへ統合できるか

### 3.1 技術面 → 問題なし

| 論点 | 判定 |
|------|------|
| サーバー不要か | ✅ 完全に静的。localStorage すら不要 |
| 静的エクスポートで作れるか | ✅ 一覧・詳細とも事前生成できる |
| 絞り込みの実装 | ✅ クライアント側のフィルタで足りる。既存の `"use client"` の使い分けに収まる |
| データの持ち方 | ✅ `lib/rec/activities.ts` に型付きで持つ。`lib/quiz/units.ts` と同じ思想 |
| UIの再利用 | ✅ `components/ui/` の Card・Button をそのまま使える |
| 文体の切り替え | ✅ 設計ガイドライン 5.6 に「保護者向け・規約類は通常の漢字表記」とあり、その延長で扱える |

**技術的な障害はない。** むしろ作り置き型コンテンツなので、静的サイトとの相性は
ドリルより良いくらいである。

### 3.2 情報設計（IA）面 → 分離すれば問題なし

懸念は「児童が来るサイトに教員向けが混ざると、何のサイトか分からなくなる」こと。
これは**URLとナビで完全に分離すれば緩和できる**。

```
/                      LP（児童・保護者向け）      … 変更なし
/learn/…               ドリル（児童向け）          … 変更なし
/teachers/             ★教員向けトップ
/teachers/rec/         ★学級レク一覧
/teachers/rec/[slug]   ★各レクの詳細
/teachers/use/         ★授業での利用について（印刷・投影の許諾）
```

**ヘッダーには出さない。** 児童が見る画面のナビゲーションは今のまま触らない。
導線はフッターの「先生の方へ」1リンクと、`/about` からの言及にとどめる。

理由は2つ。児童の画面を複雑にしないこと。もう1つは、**教員は検索から直接
`/teachers/rec/` に着地する**ので、トップからの導線に依存しないこと。

### 3.3 ブランド面 → **要件定義書の書き換えが必要**

ここだけは「ただ足す」では済まない。現在の定義はこうなっている。

> | 一言でいうと | 登録不要・完全無料の、小学生向け算数ドリルサイト |

教員向けエリアを持つなら、この一文は事実と合わなくなる。次のどちらかを選ぶ必要がある。

| 案 | 定義 | 影響 |
|----|------|------|
| **拡張する** | 「小学生の算数と、先生の学級づくりを支える無料サイト」 | サイトの器が広がる。今後もツールを足せる |
| 主従を明示する | 「小学生向け算数ドリルサイト（先生向けの資料も置いています）」 | 主軸がぶれない。教員向けは付帯物になる |

**「拡張する」を推す。** 付帯物として置くと、教員向けコンテンツを育てる判断が
毎回「本業ではないのに」という迷いを伴う。案4を取りにいくなら、器を先に広げたほうがよい。

### 3.4 リスク

| リスク | 大きさ | 対処 |
|--------|--------|------|
| **学級レク情報はすでに飽和**（検索すると即座に十数件出る） | 大 | 網羅で戦わない。「隙間時間・準備物なし」への特化と、後述の**声の大きさフィルタ**で差をつける |
| サイトの焦点がぼやける | 中 | URL・ナビで分離。児童向け画面は一切変えない |
| レクの名称・内容の出所 | 中 | **書籍からの引き写しをしない。** 一般に流通している遊びを、自分の言葉で書く。テレビ番組由来の固有名称は避け、一般名で書く（→ 6.2） |
| 更新が止まる | 小 | 作り置き型。10本作れば当面追加しなくても価値が落ちない |

### 3.5 結論

**統合できる。ただし要件定義書の「一言でいうと」を書き換えることを条件とする。**

技術的な障害はなく、静的サイトとの相性は良い。IAは `/teachers/` 配下に隔離することで
児童向けの体験を一切損なわずに追加できる。残る論点はブランドの定義だけであり、
それは意思決定で解ける。

## 4. 仕様

### 4.1 データモデル

`lib/rec/types.ts`

```ts
/** 声の大きさ。隣のクラスが授業中かどうかで選べるようにするための軸。 */
export type Volume = "silent" | "normal" | "lively";

/** 隊形。教室のどこまで動くか。 */
export type Formation = "seated" | "stand" | "move";

export type RecActivity = {
  slug: string;
  name: string;
  /** 一覧に出す1行。何をする遊びかが分かること */
  summary: string;
  /** 説明込みの所要時間（分）。上限を書く */
  minutes: 1 | 2 | 3 | 5;
  volume: Volume;
  formation: Formation;
  /** 準備物。なければ空配列 */
  materials: string[];
  /** 学年の目安。[下限, 上限] */
  grades: [number, number];
  /** 手順。1文1手順、5手順以内 */
  steps: string[];
  /** 現場での勘どころ。ここがこのサイトの価値 */
  tips: string[];
  /** つまずきやすい点・やめどき */
  cautions: string[];
  /** 慣れてきたときの変化形 */
  variations?: string[];
  /** 算数と地続きなレクにだけ付ける。該当単元へのリンクになる */
  relatedUnit?: string;
};
```

### 4.2 一覧ページ `/teachers/rec/`

**絞り込み軸**（すべてクライアント側、URLクエリに反映しない）

| 軸 | 選択肢 | なぜ要るか |
|----|--------|-----------|
| **時間** | 1〜2分 / 3分 / 5分 | 残り時間で決まる |
| **声の大きさ** | 静か / ふつう / にぎやか | **隣が授業中だと、盛り上がるものは選べない。他サイトにない軸** |
| **隊形** | 席のまま / 立つ / 教室内を動く | 机を寄せる余裕があるかで決まる |
| **準備物** | なしのみ表示 | いちばん多い制約 |

**表示**

- カード1枚に「名前 / 1行説明 / 時間 / 声 / 隊形 / 準備物」を出す
- **一覧の時点で選べる情報量を持たせる。** 詳細を開かずに決められることを目標にする
- 既定の並びは「時間が短い順」

### 4.3 詳細ページ `/teachers/rec/[slug]`

上から順に、教室で読む順序に合わせる。

1. **名前**
2. **条件バッジ**（時間・声・隊形・準備物・学年）
3. **どんな遊びか**（2〜3文）
4. **やり方**（番号付き。5手順以内）
5. **先生のひとこと**（勘どころ。ここが読ませたい部分）
6. **気をつけること**（トラブルの芽・やめどき）
7. **慣れてきたら**（変化形）
8. 算数と地続きなものは、該当ドリルへのリンク

**印刷を考慮する。** A4縦1枚に収まる分量に制限し、印刷時は絞り込みUIとナビを隠す。

### 4.4 教員向けトップ `/teachers/`

- このエリアが何かの説明（3〜4文）
- 学級レクへの導線
- 授業での利用について（`/teachers/use/`）への導線
- 「現役の小学校教員が作っています」の一文
  - **肩書きだけを置かない。** 「隙間時間に使えるものだけに絞ってあります」のように、
    その立場から何を判断したかを書く（→ x-operations.md 2.2）

### 4.5 授業での利用について `/teachers/use/`

ゆみねこの教科書が持っている「先生方へ」ページに相当するもの。
教員は「使っていいのか」で手が止まるため、先に消しておく。

明示する内容（案）:

- 学級での口頭利用、黒板への板書、電子黒板への投影、学習端末での表示を認める
- 印刷して配布することを認める
- 校内研修資料への引用を認める（出典の明記を条件とする）
- 有償の教材への転載、サイト全体の複製は認めない

> **未確定:** 具体的な許諾範囲は運営者の判断が要る。上記は原案であり、
> 確定前に `/terms` との整合を取ること。

### 4.6 文体

児童向けドリルとは切り替える。

| 項目 | 設定 |
|------|------|
| 表記 | 通常の漢字。ひらがな化しない |
| 語尾 | です・ます |
| 一人称 | わたし |
| 断定 | 避ける。「〜と思います」「クラスによります」 |
| 児童の呼び方 | 「子ども」。「児童」は硬いので使い分ける |
| 避ける | 「絶対に盛り上がる」「必ず成功する」などの断定、他の実践への批判 |

## 5. 掲載する学級レク（初期10本）

すべて **5分以内・準備物ほぼなし・教室で成立** の条件を満たすもの。

> **重要な但し書き:** 以下の「先生のひとこと」は、一般に知られている運用上の勘どころを
> 書いたものであり、**運営者本人の実体験ではない。** 公開前に必ず自分の実感と
> 突き合わせ、ずれているものは書き換えるか削ること。ここが本サイトの価値の中心であり、
> 借り物のまま出すと差別化が消える。

### 5-1. 後出しじゃんけん（負ける手）

| | |
|---|---|
| 時間 | 1〜2分 |
| 声 | ふつう |
| 隊形 | 席のまま |
| 準備物 | なし |
| 学年 | 1〜6年 |

**どんな遊びか**
教師が出したじゃんけんの手に対して、子どもは「後出しで、わざと負ける手」を出します。
勝つのは簡単ですが、負けるのは頭の切り替えが要ります。

**やり方**
1. 教師が「じゃんけん、ぽん」で手を出す
2. 子どもは半拍おいて、その手に**負ける手**を出す
3. 間違えた人は座ったまま手を下ろす
4. 最後まで残った人が勝ち

**先生のひとこと**
- 最初の2回は「勝つ手」で練習してから、負ける方に切り替えると全員が乗ります
- テンポを上げるほど難しくなるので、速さで難易度を調整できます

**気をつけること**
- 「間違えたら負け」を厳しく取ると、下位学年では泣く子が出ます。**自己申告制**にして、
  周りが指摘しない約束を先に作ると穏やかに回ります

**慣れてきたら**
「あいこの手を出す」に変えると難易度が上がります。

### 5-2. 3の倍数で手をたたく

| | |
|---|---|
| 時間 | 2〜3分 |
| 声 | ふつう |
| 隊形 | 席のまま |
| 準備物 | なし |
| 学年 | 3〜6年 |
| 関連単元 | 九九・倍数 |

**どんな遊びか**
席の順に1、2、3…と数を言っていきますが、3の倍数のときだけ数を言わずに手をたたきます。

**やり方**
1. 列の先頭から順に、1つずつ数を言う
2. 3の倍数（3、6、9…）のときは数を言わず、手を1回たたく
3. 間違えたら、その列の最初に戻る
4. 30まで到達したら成功

**先生のひとこと**
- 「間違えたら戻る」を全体でやると1人の失敗が重くなります。**列ごとに競わせず、
  クラス全体で30を目指す形**にすると、間違えた子を責める空気になりにくいです
- 3の段が定着していない子には、指を折って数える時間を許すと参加できます

**気をつけること**
- 4の倍数・7の倍数に上げると急に難しくなります。3から動かさなくても十分成立します

**慣れてきたら**
「3の倍数で手をたたく」に「5の倍数で立つ」を重ねます。

### 5-3. 拍手まわし

| | |
|---|---|
| 時間 | 2〜3分 |
| 声 | 静か |
| 隊形 | 席のまま |
| 準備物 | なし |
| 学年 | 1〜6年 |

**どんな遊びか**
拍手を1つずつ隣へ回していきます。声を出さないので、隣のクラスが授業中でも使えます。

**やり方**
1. 教師が最初に1回手をたたき、隣の子へ回す
2. 受け取った子は1回たたいて、次の子へ回す
3. 一周する時間を計る
4. 2周目は記録の更新を目指す

**先生のひとこと**
- **記録を計ると空気が変わります。** 1周目は雑でも、タイムを出した瞬間に集中します
- 一周30秒を切るあたりから、子どもが自然に「前の人を見る」ようになります

**気をつけること**
- 速さを求めすぎると、たたく前に手が出て順番が崩れます。崩れたらそこで一度止めます

**慣れてきたら**
2回たたいたら逆回り、というルールを足します。

### 5-4. せーので数える

| | |
|---|---|
| 時間 | 3分 |
| 声 | ふつう |
| 隊形 | 席のまま |
| 準備物 | なし |
| 学年 | 3〜6年 |

**どんな遊びか**
クラス全員で1から順に数を言います。**誰が言うかは決めません。**
同時に2人以上が言ってしまったら最初からやり直しです。

**やり方**
1. 順番を決めずに、誰かが「1」と言う
2. 続けて誰かが「2」と言う
3. 同時に声が重なったら1に戻る
4. 30まで到達したら成功

**先生のひとこと**
- **無言の時間が長く続きますが、そこを待つのがこの遊びの本体です。** 教師が
  「早く」と促すと成立しません
- 声の大きい子が続けて言い始めたときに、周りが譲る動きが出ます。そこを後で価値づけると
  学級づくりにつながります

**気をつけること**
- 「誰のせいでやり直しになったか」を言い合う空気が出たら、その場で止めます

### 5-5. 数当て（1〜100）

| | |
|---|---|
| 時間 | 3分 |
| 声 | ふつう |
| 隊形 | 席のまま |
| 準備物 | 黒板とチョーク（なくても可） |
| 学年 | 3〜6年 |
| 関連単元 | 数の大小 |

**どんな遊びか**
教師が1〜100の数を1つ決め、子どもが当てます。外れたら「もっと大きい／小さい」だけを返します。

**やり方**
1. 教師が数を1つ決めて紙に書いておく
2. 子どもが数を言う
3. 教師は「もっと大きい」「もっと小さい」だけを返す
4. 外れた数の範囲を黒板に書いていく
5. 7回以内に当たれば子どもの勝ち

**先生のひとこと**
- **7回で必ず当たります。** 真ん中を言えば範囲が半分になるからで、それに気づいた子が
  出た瞬間に説明すると、二分探索の考え方がそのまま入ります
- 気づかないうちは、当たった後に「どうすれば少ない回数で当たるか」を1分だけ考えさせます

**気をつけること**
- 範囲を黒板に書かないと、同じ数を何度も言われて時間が溶けます

**慣れてきたら**
1〜1000に広げます。回数の上限は10回になります。

| 準備物 | なし |
| 学年 | 2〜6年 |
| 関連単元 | たし算 |

**どんな遊びか**
2人で交互に数を数え、31を言った方が負けです。1回に1〜3個まで進められます。

**やり方**
1. 隣の子とペアを作る
2. 「1」から交互に数を言う。1回に言えるのは1〜3個まで（例：「1、2」）
3. 31を言った方が負け

**先生のひとこと**
- **必勝法があります。** 30、26、22…と4つおきの数を相手に言わせる形に持ち込めば勝てます
- 先に教えないこと。何回かやったあとで「勝ち方があるけど、分かった人いる？」と
  聞くと、探し始めます

**気をつけること**
- ペアの力差が大きいと一方的になります。3回やったら相手を替えると平らになります

**慣れてきたら**
上限を31から他の数に変えて、必勝の数がどう動くかを考えさせます。

### 5-7. 共通点さがし

| | |
|---|---|
| 時間 | 3分 |
| 声 | にぎやか |
| 隊形 | 席のまま（ペア） |
| 準備物 | なし |
| 学年 | 1〜6年 |

**どんな遊びか**
隣の子と話して、2人の共通点を制限時間内にできるだけ多く見つけます。

**やり方**
1. 隣の子とペアを作る
2. 2分で共通点を探す
3. 見つけた数を発表する
4. 面白かった共通点をいくつか紹介する

**先生のひとこと**
- 「制服を着ている」「小学生」のような**全員に当てはまるものは無効**と先に言っておかないと、
  数だけが伸びて会話になりません
- 学期はじめや席替え直後に置くと、話すきっかけとして機能します

**気をつけること**
- 家庭環境に触れる話題（家族構成、持ち物、習い事の有無）は出てきやすいので、
  発表させるのは本人が言ってよいものだけにします

### 5-8. かぶらせない

| | |
|---|---|
| 時間 | 5分 |
| 声 | ふつう |
| 隊形 | 席のまま |
| 準備物 | 紙とえんぴつ |
| 学年 | 4〜6年 |

**どんな遊びか**
お題に対して、**他の人と答えがかぶらないように**答えます。少数派が勝ちです。

**やり方**
1. 教師がお題を出す（例：「赤いもの」）
2. 全員が紙に1つ書く
3. 順に発表し、同じ答えの人は脱落
4. 誰ともかぶらなかった人が勝ち

**先生のひとこと**
- お題選びが全てです。**答えが3つくらいしか思いつかないお題**（「信号の色」など）だと
  全員かぶって終わります。答えが広いお題を選びます
- 「かぶらない」を狙って突飛な答えに走る子が出ますが、それはこの遊びでは正解です

**気をつけること**
- 人の名前をお題にしない。誰が選ばれた／選ばれなかったが可視化されます

### 5-9. ○×クイズ

| | |
|---|---|
| 時間 | 5分 |
| 声 | にぎやか |
| 隊形 | 立つ |
| 準備物 | なし |
| 学年 | 1〜6年 |

**どんな遊びか**
教師が出す問題に、立つ／座るで○×を答えます。間違えたら座って終わりです。

**やり方**
1. 全員が立つ
2. 教師が問題を出す（「今日は水曜日である」など）
3. ○だと思う人はそのまま、×だと思う人は座る
4. 外れた人はそのまま座って見る
5. 最後まで立っていた人が勝ち

**先生のひとこと**
- **問題はその場で作れます。** 学校のこと、今日の給食、授業でやったことから出すと
  準備がいりません
- 最初の1問は全員が分かるものにして、脱落者が出ないようにすると空気が温まります

**気をつけること**
- 早い段階で半分が座ると、残り時間が退屈になります。**難しい問題は後半に置きます**

**慣れてきたら**
子どもに問題を作らせます。

### 5-10. 声を出さずに並ぶ

| | |
|---|---|
| 時間 | 5分 |
| 声 | 静か |
| 隊形 | 教室内を動く |
| 準備物 | なし |
| 学年 | 3〜6年 |

**どんな遊びか**
一言もしゃべらずに、誕生日の順に並びます。身振りだけで伝え合います。

**やり方**
1. お題を決める（誕生日順、名前の五十音順など）
2. 声を出さずに並ぶ
3. 並び終わったら順に確認する

**先生のひとこと**
- **教室の広さによっては列ごとに分けます。** 全員で動くと机にぶつかります
- 指で数を示す動きが自然に出ます。終わったあとに「どうやって伝えた？」を聞くと、
  伝え方の工夫が共有されます

**気をつけること**
- 誕生日は言いたくない子もいます。**名前の五十音順など、代わりのお題を用意**しておきます
- 声が出た時点でやり直しにすると時間が足りません。注意にとどめます

## 6. 検索の入口

### 6.1 狙うクエリ

網羅型の記事が取りこぼしている、**条件付きのクエリ**を狙う。

| クエリの型 | 例 |
|---|---|
| 時間で絞る | 学級レク 5分 / 学活 レク 短時間 |
| 準備物で絞る | 学級レク 準備なし / 教室 ゲーム 道具なし |
| 状況で絞る | 授業 余った時間 小学校 / 給食 待ち時間 ゲーム / 雨の日 休み時間 教室 |
| 声で絞る | 学級レク 静か / 教室 静かに できる ゲーム |
| 学年で絞る | 学級レク 低学年 席のまま |

**「学級レク」単体では戦わない。** 上位は既存のブログと法人メディアで埋まっている。

### 6.2 タイトルの付け方

各詳細ページのタイトルには**条件を入れる**。

- ✅ 「後出しじゃんけん（負ける手）｜1分・準備なし・席のままできる学級レク」
- ❌ 「後出しじゃんけん｜学級レク」

### 6.3 レクの名称の扱い

**テレビ番組由来の固有名称は使わない**（権利関係が不明確なため）。
一般に流通している呼び名か、内容がそのまま分かる名前を付ける。
書籍から手順を引き写さず、**自分の言葉で書く**。
