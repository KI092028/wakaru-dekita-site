## 1. 検討前に立てた3つの仮説の検証結果

### 仮説1「ドリル反復の効果量は、他の介入に比べて小さいのではないか」

**→ 部分的に正しいが、単純ではない。**

想起練習（テスト形式で思い出させる練習）は **g=0.61**（Adesope et al. 2017, 217研究）
と、今回調べた中で最も頑健な数値のひとつだった。ドリルという枠組み自体は否定されない。

しかし次の2つが痛い。

- **技術ベースの計算ドリル vs 非デジタルの紙ドリル → g=0.25**（Burns et al. 2025）。
  つまり「紙のプリントをWebアプリにしたこと」による上乗せは中程度以下でしかない。
  無料プリントサイトが17〜20も生き残っている理由の説明にもなっている。
- **宿題の効果量は小学校段階で d=0.15**（Hattie）。中学・高校では d=0.64 と跳ね上がる。
  家庭で解く反復課題という形式は、小学生に対しては元々効きにくい。

さらに **回答ベースの単純CAI は d=0.31、ステップ単位で誤りを診断するITSは d=0.76**
（VanLehn 2011）。現状のサイトは前者、つまり d=0.31 の側にいる。

**結論**: ドリルをやめる根拠はない。ただし「Webでドリルを出す」こと自体の付加価値は
測定上かなり小さい。想起練習として設計されているか、誤りを診断しているかで
効果量は倍以上変わる。

### 仮説2「保護者の本当の需要は、教材ではなく診断・説明ではないか」

**→ 需要の所在としては正しい。ただし効果量の裏付けは弱い。**

保護者の困りごとは4つに分かれ、どれも「教材が足りない」ではなかった（調査B）。

1. 教え方が自分の習った時代と違う。特に**「答えは合っているのにバツ」**が
   理不尽な体験として強く記憶されている
2. **どこでつまずいたのか特定できない**
3. 何をやらせればいいか分からない
4. **毎日の丸つけ負担**（計算ミスか理解の欠落かを区別できない）

しかし、その診断（＝形成的アセスメント）の効果量は下方修正が続いている。
Black & Wiliam (1998) は d=0.4〜0.7 と主張したが、Kingston & Nash (2011) の
再分析では **d=0.20**、**算数に限ると d=0.17** にとどまった。

一方で、**保護者に学習状況を伝える型の介入は、複数のRCTで再現性のある効果**が出ている。

- Kraft & Rogers (2015): 週次の軽量な連絡で単位取得率 +6.5ポイント（不合格41%減）。
  「できていること」より「改善点」を伝える方が効果が大きかった
- Bergman & Chan (2021): 自動テキスト通知で単位不合格27%減、出席率+12%。
  ただし標準テストの点数には有意な影響なし

逆に、**保護者が横について宿題を手伝う型の関与は効果が薄いか逆効果**である。
Patall et al. (2008) では中学校で負の関連、さらに**数学の成績には負の関連**。
ペンシルベニア州立大の研究では、SESと親の学歴を統制すると小学校段階の
宿題手伝いは有意な影響なし。

**結論**: 保護者向けに何か作るなら、「教え方の指南」ではなく
「状況の可視化・共有」に寄せるべき、という設計指針がエビデンスから導ける。
ただし可視化・共有には端末をまたぐ記録が要る。これは
「サーバーに保存しない・ログイン不要」という現在の方針と正面から衝突する。

### 仮説3「作り置き型の形式なら、リピート率は指標として不適切ではないか」

**→ 正しい。しかもこれが今回いちばん効く発見だった。**

コンテンツ資産型の教育サイトにおいて、リピート率はEC・会員ビジネス向けのLTV指標であり、
第一指標にならない。実質的な指標は**セッション数＝新規流入の総量**である（調査D）。
滞在時間も「長い＝理解に苦しんでいる」でありうるため単純に善ではない。

**「一度見て解決して二度と来ないことが成功」なサイト**として、単位換算ツール、
用語辞典ページ、Purplemath の個別レッスンページが挙げられている。

これまでのゲーム性の3回の試み（81マス制覇マップ / コンボ / テンポ）は、
すべて「リピート率を上げる」という目標の上に乗っていた。
**その目標設定自体が、この業態に合っていなかった可能性が高い。**

## 2. 市場と構造について確定したこと

### 2.1 無料プリント・ドリル市場は完全に飽和している

確認できただけで17〜20サイト。運営主体は2系統に分かれる。

- **法人のオウンドメディア型**: ちびむすドリル（株式会社パディンハウス、2008年開設・
  運営18年目・プリント2万枚超）、学習プリント.com（D.F.C／家庭教師事業への送客）、
  すたぺんドリル（イロイト／習い事送客）
- **個人の「自分の子どものために作った」型**: ぷりんときっず、
  むげんプリント（元文科省職員＋理科教員免許）、おかわりドリル（国立理系大学院卒）

**教育バックグラウンドを持つ個人が、自分の子ども・自分の教室のために作って公開する**
という参入の型は、この市場ですでに繰り返されている。現状の立ち位置そのものに
差別化はない。

**プリントサイト単体の広告収入で生計が成立している個人運営者の事例は1件も確認できなかった。**
生き残っているものは「本業への送客」「副業」「商用ライセンスのB2B課金（算願）」のいずれか。

有料側（RISU、スタディサプリ、トドさんすう、Qubena）に人が払っているのは、
個別最適化・人による解説・進捗の可視化・継続の仕組み・端末サポートであり、
**「問題そのもの」に対価が発生している例は市場全体でほぼ皆無**だった。

### 2.2 1人のまま長く続いた教育サイトは、ドリル型ではなかった

24年以上ひとりで生存している例は2つだけ確認できた。

- **Math is Fun**（2000年〜、Rod Pierce が今も個人運営）
- **Purplemath**（1998年〜、数学講師の個人開始／2012年法人化）

どちらも**解説記事＋用語辞典＋操作ツール**であり、ドリル配布ではない。

対して、個人発で規模が出たものは軒並み法人化・チーム化して継続している。
高校数学の美しい物語（2014年個人開始→2021年 株式会社ベンドと共同運営）、
ちびむすドリル（育児ブログ→パディンハウス）、ぷりんときっず（1人→2014年から複数人）、
Khan Academy（個人→NPO→助成金）。

**「1人・低い更新負荷」を制約として飲むなら、選べる形式は絞られる。**

### 2.3 日本語圏の小学校算数に、操作型ツールの空白がある

GeoGebra・Desmos は日本語コミュニティがあるが中高数学（関数・グラフ）が中心。
**小学校算数の概念（分数の意味、面積の考え方、九九の仕組み）を操作して理解させる
無料ツールは日本語圏で明らかに手薄**で、機能は学校向けデジタル教科書に囲い込まれており
家庭からは触れられない。散発的な個人公開（TKK特別支援教材開発研究所、エデアル）があるのみ。

### 2.4 教員向け市場は、ニーズはあるがマネタイズができない

一次データ:

- 平日在校時間 10時間45分／授業準備 1日1時間15分
- **自腹率 75.8%**（School Voice Project, 1,034名）
- 加配未配置校で「人的措置なし」が 28.2% → 64.4% に倍増
- 通常学級の 8.8% が学習面・行動面で著しい困難（文科省）

一方で、校務支援（EDUCOM C4th）・授業支援（ロイロノート＝導入13,000校・1日280万人）は
大手の寡占で、個人参入の余地は事実上ない。プリント共有（TOSSランド、授業準備ネット）も飽和。
**唯一、個人参入が可能になった領域は所見文例生成などLLM以後のツール**だが、
「校費が使えない・自腹への抵抗」という構造から収益化事例は確認できなかった。

## 3. 調査結果どうしの矛盾（重要）

意思決定の前に、必ず認識しておくべき食い違いが3つある。

### 矛盾1: 「空白がある」ことと「そこで勝てる」ことは別

調査AもDも「概念可視化」「つまずき診断」を空白として推している。
しかしDの同じ調査の4節はこう報告している。

- 「分数 通分 やり方」のような**悩みクエリの上位は進研ゼミ／ベネッセ等の法人メディアが占める**
- 個人ドメインが強いのは**「算数 プリント 無料」のような教材探しクエリ**

つまり**推奨されている案は、自分の調べた検索構造上いちばん不利な入口を流入経路として前提にしている。**
空白が空白のまま残っているのは、そこが儲からず・人が来にくいからかもしれない。
空白は必ずしも機会ではない。

### 矛盾2: 「診断」の推奨順位は効果量に基づいていない

調査Cは「つまずきの診断＋可視化」を第1位に挙げたが、その根拠として引いた
形成的アセスメントの効果量は**算数で d=0.17** である。第3位に置かれた
想起練習の **g=0.61** より明確に低い。

Cが診断を1位にした理由は効果量ではなく「静的サイトでも実装可能」という媒体適合性だった。
これは正当な考慮だが、**エビデンスの強さで1位なのではない**ことは明記しておく必要がある。

### 矛盾3: 最も証拠が強い介入は、現在の方針では実装できない

保護者への学習状況通知は、今回集めた中で最もRCTの裏付けが強い（Kraft & Rogers,
Bergman & Chan）。しかしこれには端末をまたぐ記録の保持と通知手段が要る。

現在の方針は「サーバーに保存しない・ログイン不要・localStorageのみ」。
**この方針を維持する限り、最も効果の証拠が強い介入は選択肢から外れる。**
これは機能の話ではなく方針の話であり、選ぶなら方針ごと変更する判断が要る。

### Hattie の数値の扱いについて

上で引いた d 値の多くは Hattie の Visible Learning に由来するが、
これには重い統計的批判がある。Bergeron & Rivard (2017) は相関の効果量への変換の欠陥、
相関と因果の混同、CLE確率値が -49%〜219% という論理的にありえない値になる点を指摘し
「疑似科学」と断じている。Simpson (2017) も、効果量は個別研究の分析道具であって
政策指針の道具ではないと批判している。版によって同じ項目の d 値が 0.1 前後動く。

**Hattie 由来の数値は目安として扱い、精密な意思決定の根拠にはしない。**
個別のメタ分析（Adesope 2017, Burns 2025, Kingston & Nash 2011, VanLehn 2011,
Patall 2008）の方を重く見るべきである。

## 4. 選択肢の比較

以下は択一ではなく、組み合わせもありうる。それぞれ「何を賭けているか」が異なる。

### 案1: 現状路線の純化 — 想起練習ドリルとして最適化する

| | |
|---|---|
| **賭けている前提** | 教材探しクエリからの流入は個人にも取れる。ドリルは設計次第で効く |
| **エビデンス** | 想起練習 g=0.61。ただしデジタル化の上乗せは g=0.25、小学校の宿題は d=0.15 |
| **強み** | すでに動いている。入力式への変更はこの方向に正しく踏み出している。コストが最も低い |
| **リスク** | 10〜18年のSEO資産を持つ17〜20の競合。差別化がない。効果の天井が測定上わかっており、それは高くない |
| **必要な更新頻度** | 低（単元追加のみ） |

補足: 直近の「4択→入力式」の変更は、選択肢からの再認を想起に変えるもので、
g=0.31 の回答ベースCAI から g=0.61 の想起練習へ寄せる方向として理論的に正しい。
**この案を選ぶ場合、やることは「ゲーム性の追加」ではなく
「間隔をあけた再出題」と「誤答の質の判定」である。**

### 案2: つまずきの診断・系統図 — 「どこに戻ればいいか」を示す

| | |
|---|---|
| **賭けている前提** | 保護者の最大の困りごと（どこでつまずいたか分からない）に、現役教員の暗黙知で応えられる |
| **エビデンス** | 弱い〜中程度。形成的評価は算数で d=0.17。ただしステップ単位の診断を伴うITSは d=0.76。Brown & Burton (1978) の「誤答はランダムでなく規則的なバグである」は理論的支柱になる |
| **強み** | **現役教員であることがそのまま参入障壁になる唯一の領域**。作り置き型で更新負荷が低い |
| **リスク** | 悩みクエリは法人メディアが占有。一次情報がなければ教科書会社の系統表の焼き直しになる |
| **必要な更新頻度** | 非常に低 |

補足: この案の成否は「本物の一次情報を持っているか」に尽きる。
すでに 「分数でつまずくのは通分・約分の作業である」 という具体的な現場知が出ている。
これは公開情報からは出てこない類の知識であり、この案の核になりうる。
逆にこの種の知見を単元数だけ並べられないなら、この案は成立しない。

### 案3: 概念を操作して理解する可視化ツール

| | |
|---|---|
| **賭けている前提** | 日本語圏の小学校算数に操作型ツールの空白があり、そこは埋める価値がある |
| **エビデンス** | **今回の調査では効果量を確認できていない**（調査Cの守備範囲外だった）。空白の存在は確認できたが、効くという証拠は取れていない |
| **強み** | 作り置き型で1人運営に最も適合（Math is Fun が24年これで生存）。明確に差別化される |
| **リスク** | 実装コストが単元あたり最大。NHK for School やデジタル教科書と比較され見劣りする危険。流入経路が悩みクエリ（不利な方） |
| **必要な更新頻度** | 非常に低 |

**この案を検討するなら、操作型教材・マニピュラティブの効果量を追加調査すべきである。
現状、4案の中で唯一エビデンスの裏付けがない。**

### 案4: 教員向けに戻る（「先生の道具箱」の再評価）

| | |
|---|---|
| **賭けている前提** | 放棄した方向にこそ、他人が真似できない優位があった |
| **エビデンス** | 教員の時間的窮乏は一次データで裏付けられている（在校10時間45分、自腹75.8%、加配なし64.4%） |
| **強み** | **流入経路の問題に唯一答えがある**。教員コミュニティへの導線を本人が持っている。SEOで18年物のドメインと戦わなくてよい。席替えツールのような制約充足系は「20サイトの1つ」ではなく「動く1つ」が勝つ領域 |
| **リスク** | 収益化はほぼ不可能（校費が使えない・自腹への抵抗）。プリント共有はすでに飽和。ドメイン名「わかる・できる」が児童向けの名前になっている |
| **必要な更新頻度** | 中（校務の季節性に追随する必要がある） |

補足: 収益化は当面保留という現在の方針の下では、
「収益化できない」というリスクは事実上コストになっていない。
一方で**流入の問題は4案の中でこの案だけが構造的に解けている**点は重い。

## 5. どの案を選んでも、先にやるべきこと

**アクセス数を一度も測っていない。**

このため現在、次のどれが起きているのか区別がつかない。

1. 人は来ているが、内容がつまらなくて離脱している
2. そもそも人が来ていない

3回のゲーム性チューニングは (1) を前提にした施策だった。もし実態が (2) なら、
どの案を選んでも同じことが起きる。作ったものが良かったかどうかを永久に判定できない。

解析ツールの導入は「見送り」としてきたが、これはプライバシー方針との衝突が理由だった。
サーバーにログを持たない・Cookieを使わない計測手段は存在するため、
**方針を維持したまま計測を始めることは技術的には可能**である（具体案は未検討）。

また、調査Dの指摘に従うなら、見るべき指標はリピート率ではなく
**新規流入の総量とその検索クエリ**である。どのクエリで来ているかが分かれば、
上の4案のうちどれに勝ち目があるかが推測ではなく事実で判断できるようになる。
