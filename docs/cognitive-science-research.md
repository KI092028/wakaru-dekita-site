# 認知科学から見た九九の練習設計

前回の調査（[game-design-research.md](./game-design-research.md)）の結論に誤りがあったため、
認知科学——特に今井むつみの記号接地論、乗法概念の発達研究、記憶と練習の研究——から見直した記録。

調査日: 2026年8月 / 対象: 九九ドリル（小2〜3年生、静的Web、localStorageのみ）

---

## 0. 前回の結論の訂正

前回の調査はこう結論していた。

> 九九は「すでに理解した事実を瞬時に想起できるようにする訓練（流暢性）」であり、
> 「7×8=56」は任意ペアの記憶に近く、意味のある構造操作ではない。
> **構造がないところに、構造化されたメカニクスは埋め込めない。**

**この結論は誤りである。** 正確には、原因と結果が逆転していた。

> 「構造がないから統合できない」のではなく、
> **「構造を剥ぎ取る設計（4択の丸暗記チェック）を選んだから、
> 結果的に構造のない任意ペアとして扱わざるを得なくなっている」**

前回は、**すでに構造を剥ぎ取った状態の九九**を観察して「九九には構造がない」と結論した。
剥ぎ取ったのは設計者自身である。

ただし前回の結論のうち、**「純粋な想起速度の反復には、ゲームメカニクスとして
意味づけできる構造が乗っていない」という部分は正しい。**
問題は九九という題材ではなく、九九の**扱い方**にある。

## 1. 九九には構造がある（前回の前提の反証）

### 1.1 干渉研究という決定的な証拠

子どもの誤答は、正解と無関係な数ではなく、
**片方のオペランドの段に属する別の答え**に集中する（オペランド関連干渉）。
7×4を間違えるとき、24（=4×6）や32（=4×8）を答える、というパターン。

> **無関係な81個の事実同士は、干渉しない。**
> 干渉が起きるということ自体が、九九が記憶の中でネットワーク構造をなしている証拠である。

De Visscher & Noël (2014) の過敏性仮説は、九九の記憶困難を
「似た事実同士が干渉しやすい記憶特性」の問題として説明しており、
九九という素材が**互いに似通った連想を大量に作る構造**を持つことを前提にしている。

### 1.2 熟達者でさえ再構成している

LeFevre et al. (1996) の内観報告研究では、成人は一桁乗算の約80%を直接検索で解いたと報告したが、
残りは規則・累加・**derived facts（7×8 = 7×7+7 など）** に頼っていた。
さらに **derived fact で解かれやすい問題ほど、検索でも時間がかかる**という相関が確認されている。

つまり「事実想起」と「概念操作」は切り分けられる2つのモードではなく、連続体である。

### 1.3 学習過程そのものが方略の推移

Siegler の重複波モデル（overlapping waves）によれば、子どもは
「数える → 累加する → derived facts → 検索」という方略を**同時に複数持ち、確率的に使い分ける**。
どの九九にどの方略を割り当てるか自体が学習対象であり、これは典型的な概念操作である。

### 1.4 埋め込める構造の一覧

| 構造 | 内容 |
|------|------|
| **交換法則** | a×b = b×a。81マスは実質45種類 |
| **分配法則（derived facts）** | 7×8 = 5×8+2×8 = 7×7+7。難しい九九を易しい九九から導出できる |
| **段の規則性** | 5の段の末尾交替、9の段の指トリック、2/4/8の倍加関係 |
| **干渉構造** | 混同しやすい組み合わせが体系的に決まっている |
| **アレイ（配列）・面積** | 9×9の正方形配列として、面積・体積、のちの多項式展開と同型 |

Zombie Division の「割り切れるかどうか」と、九九の「7×8=8×7」「7×8=7×7+7」は、
**種類は異なるが同じ意味で本物の数学的構造**である。
「概念理解を扱うゲームと違い、九九には構造がない」という二分法は成立しない。

## 2. 今井むつみの枠組みから見た診断

### 2.1 記号接地問題

記号（言葉・数字）が身体的・感覚的経験に接地していないと、使える知識にならない。
接地していない記号は、記号から記号へ漂流するだけで地面に降りられない
（今井氏はこれをAIの比喩として「永遠のメリーゴーランド」と呼んでいる）。

### 2.2 生きた知識と死んだ知識

- **死んだ知識**: 断片的で、いつ・どこで・どう使うかわからない。丸暗記で得られ、
  テストの解答欄を埋める以外に役立たない
- **生きた知識**: 必要なときに取り出せ、他の知識と組み合わせられ、問題解決に使え、
  そこから新しい知識を生み出せる

『学力喪失』（2024）には、**九九を覚え筆算も覚えたが「かけ算をいつ使ったらよいかわからない」状態**を
死んだ知識の例として挙げた趣旨の記述があるとされる（→ 6章の但し書き参照）。

### 2.3 現状のドリルへの診断

| 概念 | 現状の何が問題か |
|------|-----------------|
| 記号接地 | 出題も採点も「式→数値」の記号対記号のマッチングのみ。量的イメージへの参照がゼロ |
| 生きた知識/死んだ知識 | **4択では、生きた知識と死んだ知識のどちらが育っているか原理的に判別できない。** 接地していてもいなくても、練習すれば速くなる |
| 想起 vs 再認 | 4択は「選ぶ」であって「自分の頭から生成する」ではない。25%は偶然当たり、消去法も効く |
| スキーマ | 交換法則・段内の増分関係に触れる場面が皆無。81個の孤立事実として提示され続けている |
| ブートストラッピング | 子どもが規則を発見し自力で広げる余地がない。用意された問題に反応するだけ |

### 2.4 問題の再定義

前回の調査は「ゲームとして退屈」という問題として診断した。
今井氏の枠組みで見ると、これはより重い問題になる。

> 面白いかどうか以前に、現在の設計（意味づけなしの4択反復）は、
> **今井氏が学力不振の原因として名指しする「死んだ知識の量産構造」そのものになっている可能性がある。**

九九が流暢になるほど「答えは出せるが意味はわからない」状態が固定化されるリスクすらある。
（ただしこの因果を今井氏が明言している箇所は確認できていない。理論からの帰結としての解釈）

## 3. 実測: 現状の選択肢は九九の構造を無視している

`lib/quiz/choices.ts` の `buildChoices()` が生成する選択肢を、81通り×各300回で測定した。

| 測定項目 | 結果 |
|----------|------|
| 誤答が実際の混同パターン（同じ段の別の答え）である割合 | **33.8%** |
| **九九表に存在しない数**（＝計算せず消去できる）の割合 | **43.6%** |
| 1問あたり混同パターンが1つ以上含まれる確率 | 57.4% |
| **誤答3つすべてが九九表に無い数だった問題** | **16.4%** |

`7 × 4 = 28` の実際の出力例:

```
24 , 31 , 32 , 28      ← 31 は九九表に無い
30 , 28 , 32 , 23      ← 30, 23 が九九表に無い
26 , 31 , 29 , 28      ← 26, 31, 29 すべて九九表に無い
```

**6問に1問は、九九を1つも計算せず「九九表にありそうな数」を選ぶだけで正解できる。**

現状の実装は「正解 ±1〜5 のランダムな数」で選択肢を作っており、九九の構造と無関係である。
本来混ぜるべきは 24（4×6）、32（4×8）、21（7×3）といった**実際に子どもが混同する数**。

これは面白さ以前に、**測定しているものが九九の力ではない**という問題である。

## 4. 記憶と練習の研究から

### 4.1 検索練習効果（retrieval practice）

- Adesope et al. (2017) メタ分析: **g = 0.61**（95%CI [0.58, 0.65]）
- 7つの独立したメタ分析・12万人超のデータで **d = 0.40〜0.61** に収束。
  教育心理学で最も頑健な知見の一つ
- Ophuis-Cox et al. (2023) は**九九そのもの**を対象に、実際の教室で
  再学習より検索練習の方が流暢な想起を強く伸ばすことを示した
- **検索努力仮説**: 想起にかかる努力が大きいほど、成功時の記憶強化が大きい。
  「すぐ出た」より「うんうん考えてギリギリ出た」方が忘れにくくなる

### 4.2 生成効果（generation effect）

Slamecka & Graf (1978)。「読む」より「自分で生成する」方が、再認・再生・確信度すべてで成績が高い。

再認（4択）は再生（入力）より一貫して易しい。
4択は検索の負荷が小さく、**楽に正解できてしまう＝強化が弱い**形式にあたる。

> 注: 「4択 vs 数値入力」の直接比較による定量的な効果量差は、
> 査読済みの一次資料を確認できていない（→ 6章）。

### 4.3 望ましい困難（desirable difficulties）

Bjork。学習を難しく感じさせる条件が、短期的な成績を下げても長期的な保持を高める。

**新忘却理論**: 記憶には保存強度と検索強度があり、
検索強度が下がって「思い出しにくくなった」状態からの想起成功が保存強度を大きく伸ばす。
**忘れかけていること自体が学習のチャンス**。

**流暢性の錯覚**: 繰り返し読む・同じ問題を集中的に解く練習は「できている感覚」を生むが、
その感覚は長期保持の予測因子として当てにならない。

> **設計上の含意**: 子どもの「簡単だった」という手応えをそのままゲーム内評価に直結させると、
> **逆効果な練習を「良い練習」として強化してしまう。**
> 「パッと解けた」は報酬ではなく、「そろそろ相手を変える合図」として扱うべき。

### 4.4 間隔反復（spaced repetition）

- Cepeda et al. (2006) メタ分析: 317実験・839効果量で、分散学習が集中学習より長期保持で一貫して優れる
- Leitner システム（箱を移動）、SM-2（自己評価に基づく間隔計算）
- **successive relearning**: 正解するまで想起練習を続け、それを数日おきに繰り返す

### 4.5 交互配列（interleaving）

Taylor & Rohrer (2010): 子どもに数学の4種類の問題をブロック/交互で練習させた結果、
**交互配列は練習中の成績を悪化させたが、1日後のテストでは正答率がほぼ2倍**になった。

ただし学習のごく初期はブロック練習が有効。**ブロック → 交互配列**の2段階が妥当。

### 4.6 認知的負荷と自動化

Sweller。ワーキングメモリの制約（処理として扱えるのは2〜4チャンク程度）。
九九の自動化が重要なのは、**筆算・分数・文章題が「九九を考えずに呼び出せること」を前提に組まれている**ため。

**seductive details 効果**: 装飾的だが理解に寄与しない要素は外在的負荷を増やす。
判断基準は「装飾かどうか」ではなく「**その要素が九九の想起と直接結びついているか**」。

### 4.7 フィードバック

タイミング（即時/遅延）そのものより、**フィードバック後に何をさせるか**の方が重要
（Butler, Karpicke & Roediger, 2007）。
間違えたとき、正答を見せて終わりにせず、**直後にもう一度自分で入力させる**（訂正的検索）。

## 5. 設計への示唆

### 5.1 三者が独立に一致した唯一の点

**4択をやめ、答えを自分で作らせる（数値入力）。**

- 心理学: 再認から想起へ。有能感の証拠として質が上がる
- 記憶研究: 生成効果と検索努力仮説の両方に適う
- 今井理論: 生きた知識の要件「必要なときに自分で取り出す」に近づく
- 実測: 現状は6問に1問が計算不要で解ける（→ 3章）

### 5.2 構造を出題と演出に反映する

| 施策 | 内容 |
|------|------|
| **交換ペアを近づける** | 7×8の数問以内に8×7を出す。「さっきと同じだ」と子ども自身が気づく＝アブダクション推論の体験 |
| **段内の増分を見せる** | 同じ段を連続で出す場面を作り、「7ずつ増えている」に気づかせる |
| **derived fact をヒントに** | 間違えたとき正答を見せるだけでなく「7×8は7×7に7を足した数」と示す。複数経路からアクセスできる記憶を作る |
| **選択肢を干渉研究に基づいて作る** | 実際の混同パターン（同じ段の別の答え）を混ぜる。診断にも使える |
| **アレイを時々見せる** | 新出マスまたは連続誤答マスに限り、56を「7×8のマス」として見せる＝記号接地 |
| **タイ問題を足場に** | 6×6 のような同数問題は易しい。新しい段の導入や、連続不正解後の回復に使う |

### 5.3 間隔反復を「隠さず見せる」

WaniKani は復習間隔（4時間→8時間→1日→…→4ヶ月）を**日数ではなくステージ進行**として見せる。
Memrise は忘却を**「植物がしおれる」**として表現する。

> 九九ひとつひとつを生き物とし、時間が経つと元気度が下がる。
> 今日は弱ってきた子に会いに行く。正解すると元気になり、次に弱るまでが長くなる。

これは間隔反復アルゴリズムそのものだが、子どもには「今日会いに行く子のリスト」としか見えない。
**アルゴリズムの状態そのものが遊びの対象**になる点で、
前回の「結果の記録」だったマップとは質が異なる。

### 5.4 発想の転換: 1つのループに統合しようとするのが誤り

鍛えている能力が異なるものを、同じ10問クイズに混ぜると、
何を伸ばしているのか子どもにも運営側にも分からなくなる（現状の問題そのもの）。

| モード | 鍛えるもの |
|--------|-----------|
| **はやさ九九** | 想起の自動化。数値入力＋過去の自分との比較 |
| **みつける九九** | 交換法則・増分パターンの発見。正誤より発見が主目的 |
| **つかう九九** | どんな場面がかけ算かの判断。今井氏が問題視する部分に直接対応 |

前回は候補をすべて「1つのドリルへの機能追加」として並べていたが、
**そもそも別物として分けるべきだった**可能性が高い。

### 5.5 やってはいけないこと（前回から更新）

| 項目 | 理由 |
|------|------|
| **「速く解けた」を報酬にする** | 望ましい困難に反する。速さと理解は別物であり、「速い＝わかっている」というメッセージは記号接地なき自動化を肯定してしまう |
| **コンボ表示** | 前回の指摘（苦手な子ほど失敗の可視化装置になる）に加え、上記の理由でも不適 |
| **自己申告に依存したスケジューリング** | **7〜8歳では努力の自己評価と記憶の関係が未発達**（努力ヒューリスティックの使用は9〜12歳頃から）。自己申告は儀式にとどめ、正誤と反応時間で決める |
| **累加の枠組みだけで反復させる** | 「かけ算＝足し算の繰り返し」に留まると、のちの小数倍・割合でつまずく。アレイ（面積的な見え方）を混ぜる |
| **無関係な装飾・ミニゲーム** | seductive details 効果。九九の想起と直接結びつく要素だけに絞る |
| **強いタイムプレッシャー** | 数学不安の懸念（ただし論争的 → 6章）。速さを測るなら「過去の自分との比較」に閉じる |
| **九九ドリル単体で文章題まで解決できると考える** | 状況→式の変換は別スキル。練習量を増やしても育たない |

### 5.6 現状のうち、維持すべきもの

- `pickCells` の優先出題（にがて → あと1回 → 未挑戦 → 復習）は
  検索練習・間隔反復の知見と整合的。**壊す必要はない**
- マスターを取り消さない設計は、学習性無力感を避ける観点で妥当。**維持すべき**
- 時間制限がないことも妥当

## 6. 調査の限界

- 3本の調査とも、環境のネットワーク制約により**論文PDF本文や書籍原文に直接アクセスできず、
  検索結果のスニペットから再構成**している
- **今井むつみ氏の著書本文・原論文には直接アクセスできていない。**
  『学力喪失』の「九九を覚えたが、かけ算をいつ使ったらよいかわからない」という記述は、
  複数の書評・紹介記事で一致して言及されるが、**正確な文言・前後の文脈は未確認**
- **「接地された九九」を今井氏が具体的に定義した記述は見つかっていない。**
  本文書の記述は記号接地理論の一般原則からの敷衍であり、調査者の推論を含む
- 今井氏が九九ドリル・計算アプリの教材設計に直接関与した事例は確認できなかった。
  「たつじんテスト」は**診断ツールであって練習ツールではない**
- 「6×8の誤答率63%」「オペランド関連誤答が子どもの誤答の75.7%」等の具体的な数値は、
  複数の二次情報源で一致するが一次論文は未確認。**傾向は信頼できるが数値は参考値**
- **「4択 vs 数値入力」の直接比較による定量的な効果量差**は、査読済み一次資料を確認できていない。
  理論的整合性は高いが、効果量は未確認
- **「構造理解を組み込んだ九九ドリルが、そうでないドリルより流暢性到達を速める」という
  九九領域限定の直接的な実証**は見つかっていない
- タイムプレッシャーと数学不安（Boaler ら）は教育研究コミュニティ内で**論争が続いており未決着**
- 反応時間を間隔反復のスケジューリングに使う設計思想は、一般に知られた考え方として述べたが、
  決定的な一次資料は特定できていない
